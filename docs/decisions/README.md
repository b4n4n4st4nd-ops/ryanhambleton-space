# Decision records

Store Architecture Decision Records (ADRs) here.

Suggested filename: `YYYYMMDD-short-title.md`

[`DECISIONS.md`](../../DECISIONS.md) at the repository root is the chronological summary index. Each ADR added here should be linked from a row in that table.

This repository serves **production**. Decisions that affect deployment, the Vercel project, domains, DNS, environment variables, or paid third-party services need explicit approval from Ryan before they are recorded as settled.

Do not invent decisions. Only record choices after explicit user approval or verified evidence.
